# 竞品与模式研究

## 参考对象

### Influenster

- 采用“完善兴趣资料 → 获得匹配资格 → 收到通知 → 领取免费产品 → 完成任务”的闭环。
- 值得借鉴：把免费、匹配和任务说得很直接；用户不仅领取，还能浏览社区真实评价。
- 需要避开：App Store 评价中有人抱怨长期等不到产品或不清楚资格原因。我们的机会是展示“为什么适合你、当前名额、预计开放时间”。
- 来源：[Influenster App Store](https://apps.apple.com/us/app/influenster-try-review/id917701230)、[Influenster 用户评价](https://apps.apple.com/us/app/influenster-try-review/id917701230?platform=iphone&see-all=reviews)

### 什么值得买众测

- 官方把众测定义为免费试用，并要求用户产出真实、客观的体验报告；形式包含笔记、图文和场景众测。
- 值得借鉴：活动不是到“领取成功”结束，而是把报告沉淀为下一批用户的决策内容。
- 对本项目的启发：首页必须展示试吃报告，而不只是活动卡。
- 来源：[什么值得买商业产品—众测新品试用](https://e.smzdm.com/product)、[消费众测活动示例](https://test.m.smzdm.com/p/14422/?probation_new_type=2)

### Nike SNKRS

- 核心不是商品列表，而是新品发售故事、Upcoming 日历、通知提醒和专属资格。
- 值得借鉴：用大幅产品视觉制造“新品时刻”，将即将开放的商品做成可订阅的事件，而不是灰色不可点击卡。
- 对本项目的启发：筹备新品应该提供“开抢提醒”，并用日期轴或 Drop 卡片展示。
- 来源：[Nike SNKRS App Store](https://apps.apple.com/us/app/nike-snkrs-sneakers-apparel/id911130812?platform=ipad)、[Nike SNKRS 官方介绍](https://www.nike.com/es/snkrs-app/)

### 小红书

- 官方定位是围绕兴趣发现和真实分享的生活社区，视觉发现优先于说明文字。
- 值得借鉴：图片先建立兴趣，再由标题和标签解释；内容流天然适合食物、场景和口感表达。
- 对本项目的启发：卡片应从“包装占位图 + 运营状态”转成“真实食物封面 + 一句话判断 + 资格状态”。
- 来源：[小红书 App Store](https://apps.apple.com/cn/app/%E5%B0%8F%E7%BA%A2%E4%B9%A6-%E4%BD%A0%E7%9A%84%E7%94%9F%E6%B4%BB%E5%85%B4%E8%B6%A3%E7%A4%BE%E5%8C%BA/id741292507)

### 得物

- 强调平台查验、统一履约和全流程可信，视觉上围绕单个商品建立强焦点。
- 值得借鉴：资格、履约和平台保障应该被设计成可感知的“可信服务”，而不是藏在长规则里。
- 对本项目的启发：把“一人一份、资格有效、履约有记录”压缩为固定信任条，减少解释文字。
- 来源：[得物 App Store](https://apps.apple.com/cn/app/%E5%BE%97%E7%89%A9-%E5%BE%97%E5%88%B0%E7%BE%8E%E5%A5%BD%E4%BA%8B%E7%89%A9/id1012871328?platform=ipad)

## 用户已经形成的预期

- 免费必须在第一眼说清楚，不能让用户先猜是否需要付款。
- 即将开放的商品应支持提醒或收藏，而不是只有“筹备中”。
- 商品发现以真实图片为主，规则在详情中逐步展开。
- 资格为什么发给我、什么时候开放、还剩多少名额必须透明。
- 真实报告是平台可信度和复访理由，而不仅是商家的后台数据。

## 可形成差异化的空位

1. **食品专属的口感语言**：脆度、甜度、香气、回味和复购意愿形成统一的“试吃雷达”。
2. **试吃护照**：用户每认真完成一次就盖一个章，完成率越高，越容易获得稀缺新品资格。
3. **从研发到上市的连续故事**：到样、拍摄、开放试吃、报告汇总、正式上市在一条时间线上。
4. **把反馈变成内容**：每个活动结束自动生成“100 人怎么评价这款新品”的编辑报告。

## 不建议照搬

- 不照搬小红书的无限瀑布流：本项目活动数量有限，需要明确状态和截止时间。
- 不照搬 SNKRS 的稀缺炒作：食品试吃要强调匹配和真实反馈，不制造虚假紧迫感。
- 不照搬传统众测的长规则页：关键信息应在卡片上先说人话，完整规则再逐层展开。

## 第二轮食品 App 视觉研究（2026-08-25）

用户明确反馈上一轮仍不够美观。重新对照食品 App 后，问题不在配色细节，而在于页面仍以流程、票券和抽象包装为主，食物没有成为视觉主角。

### 新增参考

- **Too Good To Go**：官方商店截图使用满版野餐与食物场景，粗体白字直接覆盖在照片上；绿色负责品牌识别，真实食物负责情绪。来源：[Google Play](https://play.google.com/store/apps/details?id=com.app.tgtg&hl=en_US)、[官方使用说明](https://www.toogoodtogo.com/en-us/how-does-the-app-work)。
- **Tasty**：首页首卡以大幅成品图和叠字标题构成，页面背景使用高纯度粉、蓝色，但食物本身不被装饰元素抢走。来源：[Google Play](https://play.google.com/store/apps/details?id=com.buzzfeed.tasty&hl=en_US)、[Tasty](https://tasty.co/)。
- **Food52**：以编辑精选和自然光食品摄影建立品质，页面更接近食物杂志而非商品后台。来源：[Food52](https://food52.com/)。
- **山姆商品图争议**：商品主图过度美化后引发“失真”争议，随后果蔬、肉类等头图改回实拍；食品视觉必须同时满足食欲与可信。来源：[FoodTalks 报道](https://www.foodtalks.cn/news/59827)。

### 本轮直接采用的模式

1. 真实食物图先于品牌话术，首屏只讲一款主推试吃。
2. 标题可以叠在图片上，但价格、名额和按钮必须位于稳定的高对比区域。
3. 颜色用于分区和资格贴纸，不给每个模块重复加边框、印章和装饰。
4. 食物质地要真实，避免像广告渲染图；筹备新品允许标明“样品图/到样中”。
5. 首页从“解释平台”转为“今天有什么值得尝”。

## 第三轮：把“食品陈列”改成“第一口之前”（2026-08-25）

### 本轮目标

让用户在手机首屏先产生“想咬一口”的感受，再理解免费/低价试吃机制。研究只拆解成熟产品的视觉规律，不复制其品牌素材、图标或页面成品。

### 竞品模式

- **NYT Cooking**：专业食物摄影承担主要情绪价值，画面强调切面、焦边、汁水和自然光；信息区保持干净，让照片与菜名成为第一层信息。
- **美团 / 大众点评**：食物图之后紧跟评分、销量、优惠和距离等短决策信息；密度虽高，但用户无需进入详情就能判断“值不值得点”。
- **Uber Eats**：推荐流使用大图卡片和横向类别切换，把“看图选吃什么”放在“读说明”之前。
- **大众点评品质外卖**：用真实评分、带图评价和榜单标签补充信任，说明食欲感不能只靠修图，还需要真实用户证据。

### 当前页面痛点

- 三款开放试吃共用一张拼版素材，单品纹理与切面不够近，像目录图而不是食物特写。
- 首屏文案强调平台立场，但缺少“薄脆、奶香、冰凉回甘”等能够让人脑补味道的具体词。
- 首页真实反馈放得较后，商品卡也缺少评分、想试人数和口感关键词等即时决策线索。
- 详情页主要解释规则，食物图片之后马上进入机制说明，缺少“会吃到什么”和“怎么吃更好吃”的过渡。

### 采用的设计模式

- 食物画面占首屏约 70%，使用微距、切面、碎屑、冷凝水等真实质感；不生成品牌包装和虚假功效。
- 首屏增加“咔嚓 / 奶香 / 冰凉回甘”等一口级感官词，并保留价格、名额与想试人数。
- 商品卡补充口感标签和评分式社会证明，但不伪装为真实交易销量。
- 详情页在规则之前新增“第一口 → 嚼到中段 → 咽下后”的口感路径，以及最佳食用场景。

### 机会点

- 成熟外卖 App 擅长“马上下单”，本项目可以把这种食欲驱动改造成“认真试吃”：既想吃，也明确告诉用户要评价哪些具体口感。
- 让真实反馈直接贴在食物图附近，形成“食物刺激 + 他人证据 + 低门槛申请”的连续决策链。
