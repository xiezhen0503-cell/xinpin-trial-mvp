# 尖锋食客 v6：沉浸首屏与真实反馈素材

## 设计判断

对象是愿意认真试吃、愿意留下具体反馈的手机端用户。页面唯一首要任务是先激起食欲，再让用户低负担完成申请和反馈。顶部工具栏把品牌、角色切换、通知、头像同时压在首屏之前，像后台演示框架，不像食品体验产品，因此完整移除；品牌识别回到食物主图里的“尖锋食客今日开吃”印章。

## Token

- 炭黑 `#201713`：正文与味觉故事。
- 麦金 `#E6BD91`：Logo 与品牌署名。
- 辣椒红 `#D9432B`：唯一主行动色。
- 蛋黄金 `#FFD04A`：味觉提示与已选状态。
- 米浆白 `#FFF7E8`：页面底色。
- 香草绿 `#245C45`：可信、已保存、审核状态。
- 展示文字：系统中文黑体高字重，紧字距，用于“薄、脆、海苔香”等短句。
- 正文：系统中文无衬线，保持高可读性。
- 数据：系统等宽字体，用于份数、文件大小与上传状态。

## 记忆点

“第一口证据托盘”：不是通用虚线上传框，而是一块像试吃记录卡的素材区域；图片是现场证据，视频用于记录掰开、拉丝、倒出等动态口感。选择后立即出现真实内容和保存状态。

## 自我审查

- 删除顶部导航后，Logo 已在首屏、详情页和页尾出现，不会丢失品牌识别。
- 不给首页增加新的浮动装饰；大胆之处只留给沉浸式食物首屏。
- 上传不伪装成云端成功：GitHub Pages 版本把文件本体持久化到 IndexedDB，并明确标注“保存在此设备”；跨设备与商家远程查看仍需后续接入对象存储。
- 图片与视频分开选择，降低手机相册/摄像头选择歧义；限制 3 个素材、最多 1 段视频，并在失败时给出具体原因。
