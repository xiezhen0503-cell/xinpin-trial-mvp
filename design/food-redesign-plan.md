# 食品化视觉重构计划

## 页面唯一任务

让用户打开手机首页后先产生“这个看起来真好吃”的兴趣，再在同一屏内确认今天有几款能申请、是否免费，并进入试用。

## 参考结论

- Too Good To Go：用近乎满版的真实食物场景建立情绪，品牌色只负责识别和操作。
- Tasty：一张食物大图只承载一个判断，标题直接叠在图像上，卡片不用长篇解释。
- Food52：像食物杂志一样使用自然光、餐桌材质和编辑精选，让食物显得有生活感。
- 山姆商品图争议：过度修饰会损害食品信任，视觉可以精致，但必须保留真实质地和合理份量。
- 本项目此前的问题：视觉重心仍是“护照和流程”，真实食物为零；用户看到的是制度，不是味道。

## 新方向：今日试吃桌

不再把“试吃护照”作为最大视觉符号。首页像一张每天更新的试吃餐桌：食物占画面 70%，资格和规则作为贴在餐桌边缘的小票出现。

### 色彩

- 番茄红 `#E6533C`：免费、开放、主要动作。
- 奶油黄 `#FFD66B`：阳光、食欲和试吃标签。
- 菠菜绿 `#1F5D45`：可信状态、品牌识别。
- 可可黑 `#241C17`：标题和高对比信息。
- 牛奶白 `#FFF9F0`：页面底色。

### 字体角色

- 展示标题：系统中文黑体，超粗、紧字距，像食品包装正面的品名。
- 正文：系统中文无衬线，短句、较大行高。
- 日期和状态：等宽字体，像贴纸上的生产批次。

### 布局

```text
┌ 顶栏：品牌 / 今日开放数 / 通知 ┐
│ 满版今日试吃桌照片              │
│ 今日免费                        │
│ 海苔脆片，先尝再说              │
│ [免费申请] 800份                │
└──────────────────────────────┘
 口感频道：酥脆 / 低甜 / 奶香 / 鲜

 今天还能试：两张横向食物卡

 下一批到桌：两列实物/样品卡 + 提醒

 试吃员怎么说：照片感报告卡
```

### 唯一记忆点

“试吃贴纸”：每款食物图上只有一枚不规则圆角贴纸，写清 `免费试吃 / 1.9 元体验 / 等待到样`。贴纸承担资格信息，不再让护照票券压过食物。

## 自我批评后的调整

第一版构想仍想保留大面积米白、墨绿和护照章，和上一版差异不够大，也落入常见的“暖米色编辑风”。因此改为更直接的高饱和食品摄影：番茄红与奶油黄只在贴纸和分区背景出现，卡片本体减少阴影和装饰；唯一大胆位置是满版食物主视觉，其余区域保持安静。

## 验收

- 手机首屏内必须出现真实食物视觉、活动名称、价格模式与主按钮。
- 不依赖文字时也能区分三款开放活动和七款筹备新品。
- 商品图片面积不低于开放活动卡片面积的 55%。
- 提醒、详情回顶、固定 CTA、申请流程保持可用。
- 390×844 手机端无横向溢出，浏览器控制台无错误。
